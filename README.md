# Forexdle (staging)

A daily currency puzzle: name the currency from its whole history against the US dollar. Exchange rates from the Federal Reserve H.10 and Penn World Table 10.01 (CC BY 4.0), via FRED. This repository holds only the built website, served at https://fourthmeridiangames.com/forexdle-staging/
